# Cybersecurity, Systems & Curious Machines

**Understanding how systems work, exploring what intelligent machines can do, and finding the words to explain both.**

I'm a cybersecurity graduate with an AAS in Cybersecurity and CompTIA Sec+ certification, I am interested in the intersection of cybersecurity, artificial intelligence, and technical writing.

I'm particularly interested in security operations, digital forensics, and how AI can be integrated into cybersecurity workflows. I'm equally curious about AI beyond security: how language models work, what they're capable of, and how we can build useful things with them.

I learn best by experimenting, building projects, troubleshooting what doesn't work, and documenting what I discover along the way.

## What I've Been Building

### Laconia Cybersecurity Lab
*A little piece of The Expanse, running on VMware.*

My virtual enterprise environment, built to explore networking, Active Directory, Windows Server administration, and security monitoring with Splunk.

It's where I experiment with infrastructure, investigate problems, and develop practical cybersecurity skills.

[Explore Laconia →](https://github.com/BiancaSe/Laconia-Cybersecurity-Lab)

### SÝN — AI Security Agent
*Giving an AI agent access to a virtual world, one carefully defined tool at a time.*

A locally hosted AI agent built with Python, Ollama, and Flask. SÝN connects to my Active Directory lab through LDAP, allowing me to experiment with natural-language interaction, automation, and AI integration in cybersecurity.

[Explore SÝN →](https://github.com/BiancaSe/SYN-AI-Security-Agent)

### HeartBeat
*Two nodes, one connection, and a surprisingly educational amount of JavaScript.*

A real-time web application built with JavaScript, Supabase, and Cloudflare. What started as a personal idea became an opportunity to explore databases, authentication, real-time communication, and web development.

The source code is private, but I've documented the project publicly.

[Explore HeartBeat →](https://github.com/BiancaSe/HeartBeat-Project-Documentation)

## Of Spaceships, Norse Gods & Curious Machines

I'm a science fiction geek, fascinated by imagined futures, intelligent machines, Norse mythology and the occasionally questionable decisions humans make when technology gets involved.

These interests have a habit of finding their way into my technical projects.

**Laconia Cybersecurity Lab** takes its name from my favorite series *The Expanse*. My virtual machines follow the same theme, with names like Rocinante, Medina, and Tycho Station.

**SÝN**, my locally hosted AI security agent, is named after the Norse goddess associated with guarding boundaries and defending against unwanted entry. A fitting namesake for an agent designed to interact with Active Directory and explore security automation.

I like giving projects names with stories behind them. It makes the technology a little more interesting, and perhaps says something about the person building it.

Besides, if I'm going to spend hours troubleshooting a virtual network, I might as well do it aboard a really cool space ship.
